# 💡 SmartIdea
 
**Laboratório de validação de ideias do Ifes Campus Serra.**
 
A gente testa ideias antes de construir: toda ideia vira uma hipótese, a hipótese vira um protótipo e o protótipo passa por gente de verdade. O resultado decide o próximo passo — seguir em frente, ajustar ou arquivar e aprender com isso.
 
### Como trabalhamos
 
**Ideia** → **Hipótese** → **Protótipo** → **Validação** → **Aprendizado**
 
### No que estamos trabalhando
 
- Unificação das bases de dados do campus (SRC, Diretoria, Egressos e Horizon) pra facilitar o acesso às informações do Ifes Serra.
